## 3. ★ 删除/卸载按钮的准确位置与样式（需求书 §2 G5 第 2 问）

> 一句话结论：**靠右单独放**，不和"动作/打开"挤一组；它和左边那组之间隔着一个 `Spacer(weight = 1f)`，自身是 `IconButton`（35dp 高、40dp 圆角、`secondaryContainer` 底、图标+文字同色），**没有 error 红、没有描边、没有阴影**。

### 3.1 位置（三条独立证据）
1. 它在卡片底部按钮 `Row`（`:922`）里是**最后一个子项**（`:1035-1079`），之后 Row 就闭合了（`:1080`）。
2. 它和动作组之间横着一个 `Spacer(Modifier.weight(1f))`（`:999`）——这个 Spacer 就是"左侧组靠左、本按钮靠右"的分隔器；动作/WebUI 组本身也在 `Row(spacedBy 8dp)` 里（`:928`），**卸载按钮不在这个 spacedBy 里**。
3. 它的左邻只可能是"更新胶囊"，而更新胶囊自带 `padding(end = 8dp)`（`:1007`）→ 两者之间恒为 **8dp**（无更新胶囊时，左侧被 Spacer 推到最右）。

因此：**不是"和别的动作按钮同一行间距 8dp 的三连胶囊"**，而是「左组（0~2 个胶囊）——弹性空白——右组（可选更新胶囊 + 卸载胶囊）」。

### 3.2 样式（六个数值 + 一条宽度公式）

| 项 | 值 | 依据 |
|---|---|---|
| 最小尺寸 | `minHeight = 35dp` / `minWidth = 35dp` | `ModuleMiuix.kt:1036-1037` |
| 圆角 | `IconButtonDefaults.CornerRadius` = **40dp**（squircle；35dp 高时视觉=半圆），未覆写 | `[L]basic/IconButton.kt:94`、`:71` |
| 底色 | `secondaryContainer` = **#F0F0F0 / #434343**；待卸载态再乘 0.8 → **#F0F0F0@80% / #434343@80%** | `:1042`、`:1040`；色值 `[L]theme/Colors.kt:365`、`:475` |
| 内容水平内边距 | **10dp**（无更新）/ **0dp**（有更新），`animateDpAsState(tween(300ms))` | `:1045-1050` |
| 图标 | `MiuixIcons.Delete` / `MiuixIcons.Undo`，**20dp** | `:1053-1059` |
| 文字 | 「卸载」/「撤销」，**15sp / FontWeight.Medium**，`padding(start 4dp, end 3dp)` | `:1068-1076`、`:1069` |
| 前景色 | `actionIconTint` = `onSurface`@0.9（亮 #000000@90%）/ @0.7（暗 #F2F2F2@70%），图标与文字**同色** | `:773`、`:1060`、`:1073` |

**实际宽度公式**（`Box` 只给 min，宽度由内容撑开）：`10dp + 20dp(图标) + 4dp + 文字宽 + 3dp + 10dp`；「卸载」两字约 30dp → 实测约 **77dp 宽 × 35dp 高**；有更新时文字收起 → `0 + 20 + 0 + 0 + 0 + 0`，被 minWidth 夹到 **35dp 正方形**（`:1046`、`:1063-1067`）。

### 3.3 三态对照
| 态 | 图标 | 文案 | 底 | 额外动作 |
|---|---|---|---|---|
| 正常 | `Delete` | 卸载 | `secondaryContainer` | 文字与内边距均展开 |
