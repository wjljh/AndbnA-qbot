## 1. 先纠正命名：`SuperCard / SuperSwitch / SuperArrow / SuperIcon` 在源码里不存在

这是本文件最重要的一条事实，先给证据再往下写：

- SukiSU 全仓 grep `SuperCard|SuperSwitch|SuperArrow|SuperIcon` → **0 命中**（本轮实测，命令：`grep -rn 'SuperCard\|SuperSwitch\|SuperArrow\|SuperIcon' [S] --include=*.kt`）。
- Miuix 0.9.4 全库 grep `fun SuperCard|fun SuperSwitch|fun SuperArrow|fun SuperIcon` → **0 命中**（`grep -rn ... /tmp/miuixsrc --include=*.kt`）。
- 所以需求书 §2 说的四个名字，是**旧版 miuix 的 `extra.*` 命名**（0.9.x 已重组进 `basic` / `preference`），在 v4.2.1 + 0.9.4 这套组合里必须换成下表右列的真名。

## 2. SuperCard → 真实件 `Card`（miuix-ui `basic`）

### 1. 结构

```
Card(cornerRadius, insideMargin, colors)
└─ BasicCard            ← 只做底色 + 形状
   └─ Box(squircleSurface(color, cornerRadius))
      └─ Column(padding(insideMargin))
         └─ [内容]
```
`[L]basic/Card.kt:50-66`（无手势重载）、`:136-151`（带手势重载）、`:163-183`（`BasicCard`，形状来自 `squircleSurface`，`:177`）。

### 2. 文本
未使用（`Card` 不含任何文本，文本全部由调用方塞进 `Column`：`[L]basic/Card.kt:62-65`）。

### 3. 间距
- 圆角默认 **16dp**：`CardDefaults.CornerRadius = 16.dp`，`[L]basic/Card.kt:190`
- 卡片内边距默认 **0dp**：`InsideMargin = PaddingValues(0.dp)`，`[L]basic/Card.kt:195`（真正内容的 16dp 由 SukiSU 自己在内容里加，见 §6/§7）
- 卡片外边距：库不提供，由调用方给（模块卡 `horizontal 12dp / bottom 12dp`：`[S]ui/screen/module/ModuleMiuix.kt:784-786`）

### 4. 组件
组合了 1 个形状容器（`Box` + squircle）+ 1 个 `Column`；颜色走 `CardColors`（`[L]basic/Card.kt:212-216`），并通过 `LocalContentColor` 下发给内容（`:169-171`）。
SukiSU 侧不自绘任何卡片形状——两处典型用法都是裸 `Card`：模块卡 `[S]ui/screen/module/ModuleMiuix.kt:783`、设置组卡 `[S]ui/screen/settings/SettingsMiuix.kt:118`。

### 5. 交互
- 静态卡（无手势重载）不接收任何输入：`[L]basic/Card.kt:40`、`:50-67`。
- 可点重载的默认值：`pressFeedbackType = PressFeedbackType.None`、`showIndication = false`（`[L]basic/Card.kt:92-93`）→ **默认既无 ripple 也无 sink**。
- 想要 sink：显式传 `PressFeedbackType.Sink` → `SinkFeedback()`（缩放 0.94、`spring(0.8f, 600f)`：`[L]basic/Card.kt:107-108` + `[L]utils/PressFeedback.kt:31-33`）。SukiSU 唯一这么做的地方是 `WarningCard`：`showIndication = onClick != null` + `pressFeedbackType = PressFeedbackType.Sink`（`[S]ui/component/miuix/WarningCard.kt:36-38`）。
- 想要 ripple 味的叠层：显式传 `showIndication = true`，走 `LocalIndication` = `MiuixIndication`（`[L]theme/MiuixTheme.kt:32-36`），按压叠一层矩形色块（详见 §7.5）。

### 6. 状态取值
| 状态 | 底色 | 内容色 | 依据 |
|---|---|---|---|
| 正常（亮） | `surfaceContainer` = **#FFFFFF** | `onSurfaceContainer` = **#000000** | `[L]basic/Card.kt:202-203` + `[L]theme/Colors.kt:382-383` |
| 正常（暗） | `surfaceContainer` = **#242424** | `onSurfaceContainer` = **#E6FFFFFF** | `[L]theme/Colors.kt:492-493` |
| 禁用 | **不存在** | — | `Card` 没有 `enabled` 参数（`[L]basic/Card.kt:50-56`、`:87-98`），库层不给禁用暗化 |
| 按下 | 底色不变；**仅当显式 `showIndication = true` 时**才叠一层 `MiuixIndication` 矩形（alpha +0.10），默认无任何反馈 | — | `[L]utils/MiuixIndication.kt:27`、`:129-133` |

### 7. 图标
未使用。

## 3. SuperSwitch → 真实件 `Switch` / `SwitchPreference`

### 1. 结构

```
Switch(checked, onCheckedChange, enabled)          ← 自身就是 49×28dp 的胶囊
└─ Box(size 49×28, clip(CircleShape), drawBehind 画 track 矩形)
   └─ Box(size 20dp, offset(x = 25dp|4dp), graphicsLayer(scale), drawBehind 画 thumb 圆)
```
`[L]basic/Switch.kt:140-152`（track）、`:154-167`（thumb）、`:91-94`（位移）、`:96-105`（按压缩放）。

### 2. 文本
未使用（`Switch` 不带文字；文字在 `SwitchPreference` 的 title/summary 里，见 §7）。

### 3. 间距
- 控件尺寸 **49dp × 28dp**：`[L]basic/Switch.kt:143`
- thumb **20dp**：`[L]basic/Switch.kt:156`
- thumb 位移：开 **25dp** / 关 **4dp**：`[L]basic/Switch.kt:92`
- 按压时 thumb 放大到 **1.127 倍**：`[L]basic/Switch.kt:100`
- 拖动上限 ±21dp：`[L]basic/Switch.kt:175-178`

### 4. 组件
纯自绘：`Box` + `clip` + `drawBehind` + `draggable`，不依赖任何 Material `Switch`。颜色集中在 `SwitchColors`（`[L]basic/Switch.kt:262-284`），由 `SwitchDefaults.switchColors()` 给默认值（`:229-259`）。

### 5. 交互
- 点击：`Modifier.toggleable(value, onValueChange, role = Role.Switch)`（`[L]basic/Switch.kt:117-131`），切换后立刻回调并触发触感 `ToggleOn / ToggleOff`（`:123-125`）。
- 拖动：水平拖过 21/2 dp 就翻转（`[L]basic/Switch.kt:203`），过程中分档触感（`:180-194`）。
- **无二次确认**、无长按行为。
- 行级封装 `SwitchPreference` 把"点整行"也接到同一个开关上：`onClick = { onCheckedChange(!checked) }` + `role = Role.Switch`（`[L]preference/SwitchPreference.kt:87-90`）。

### 6. 状态取值（四态，逐态给全）

颜色默认值全部来自 `SwitchDefaults.switchColors()`：`[L]basic/Switch.kt:229-259`。**注意默认色彩模式（`themeMode=0` → `ColorSchemeMode.System`）走 miuix 静态调色板，下面的字面值就是真机取值**；只有开了 monet / 设了 keyColor 才变成运行时派生（见 §10 第 1 条）。

| 状态 | track 颜色变量 | track 亮色 / 暗色 | thumb 颜色变量 | thumb 亮色 / 暗色 | 依据 |
|---|---|---|---|---|---|
| 开（正常） | `MiuixTheme.colorScheme.primary` | **#3482FF** / **#277AF7** | `onPrimary` | #FFFFFF / #FFFFFF | `[L]basic/Switch.kt:235`、`:231`；`[L]theme/Colors.kt:342`、`:452` |
| 关（正常） | `MiuixTheme.colorScheme.secondary` | **#E6E6E6** / **#505050** | `onSecondary` | #FFFFFF / #FFFFFF | `[L]basic/Switch.kt:236`、`:232`；`[L]theme/Colors.kt:357`、`:467` |
| 开 + 禁用 | `disabledPrimary` | **#C2D9FF** / **#253E64** | `disabledOnPrimary` | #F3F8FF / #677993 | `[L]basic/Switch.kt:237`、`:233` |
| 关 + 禁用 | `disabledSecondary` | **#F0F0F0** / **#3F3F3F** | `disabledOnSecondary` | #FCFCFC / #797979 | `[L]basic/Switch.kt:238`、`:234` |

动态色彩（monet）分支不同：开 thumb `LocalColors.onPrimary`、关 thumb `onSurface.copy(alpha = 0.38f)`、开 thumb 禁用 `surface`——`[L]basic/Switch.kt:231-233`。**track 没有动态分支**，始终 `primary` / `secondary`。

> 关键回答（需求书 §4.2 最后一条"关闭态什么样"）：**关闭态 ≠ 灰色半透明**，track 是"次要色"实色（亮 #E6E6E6 / 暗 #505050），thumb 是纯白；开关**没有**"关闭态暗化"或"outline 描边"。

### 7. 图标
未使用（纯几何自绘）。

SukiSU 用法：模块卡直接嵌 `Switch`（`[S]ui/screen/module/ModuleMiuix.kt:893-899`），设置页用 `SwitchPreference`（`[S]ui/screen/settings/SettingsMiuix.kt:123`）。

## 4. SuperArrow → 真实件 `ArrowPreference`

### 1. 结构

```
ArrowPreference(title, summary, startAction, endActions, onClick)
└─ BasicComponent                       ← 行内核：最小高 56dp + 16dp 内边距
   └─ Layout[start | center | end]
      ├─ start  : Column(startAction)           ← 图标
      ├─ center : Column(Text title / Text summary)
      └─ end    : Row(endActions…, ArrowPreferenceEndAction)

```
`[L]preference/ArrowPreference.kt:63-88`（装配）、`:91-111`（箭头）、`[L]basic/Component.kt:159-198`（行内核布局）。

### 2. 文本
| 内容 | 字号 | 字重 | 颜色 | 依据 |
|---|---|---|---|---|
| 标题 | `textStyles.headline1` = **17sp** | **Medium** | `BasicComponentDefaults.titleColor()` → `onBackground` | `[L]basic/Component.kt:89-95`、`:272-280`；`[L]theme/TextStyles.kt:189-193` |
| 副标题 | `textStyles.body2` = **14sp** | 常规 | `onSurfaceVariantSummary` | `[L]basic/Component.kt:97-103`、`:286-294`；`[L]theme/TextStyles.kt:165-169` |

亮/暗字面值：`onBackground` = #000000 / #E6FFFFFF（`[L]theme/Colors.kt:373`、`:483`）；`onSurfaceVariantSummary` = **#99000000（60% 黑）/ #80FFFFFF（50% 白）**（`:379`、`:489`）。

### 3. 间距
- 行最小高 **56dp**：`heightIn(min = 56.dp)`，`[L]basic/Component.kt:161`

### 4. 组件
`ArrowPreference` = `BasicComponent`（miuix `basic`）+ `Image` + `MiuixIcons.Basic.ArrowRight`。它**不是** SukiSU 自绘。

### 5. 交互
- 点击整行 → `onClick`（`[L]preference/ArrowPreference.kt:85` → `[L]basic/Component.kt:146-157` 的 `Modifier.clickable`）。
- 点击反馈 = `MiuixIndication`（矩形叠层，按压 alpha 0.10），**不是 ripple、不是 sink** —— 详见 §7.5。
- 长按：无。
- 按下保持态：`holdDownState` 参数可把行锁在按压视觉（`[L]basic/Component.kt:144`），SukiSU 用它做"弹窗打开时该行保持按下"：`[S]ui/component/miuix/SuperEditArrow.kt:52`。
- 二次确认：无（是否弹窗由调用方 `onClick` 决定，例如 `SuperEditArrow` 打开输入对话框，`SuperEditArrow.kt:49-51`）。

### 6. 状态取值
| 状态 | 标题色 | 副标题色 | 箭头色 | 可点 | 依据 |
|---|---|---|---|---|---|
| 正常 | `onBackground` #000000 / #E6FFFFFF | `onSurfaceVariantSummary` #99000000 / #80FFFFFF | `onSurfaceVariantActions` **#66000000 / #66FFFFFF** | 是 | `[L]basic/Component.kt:273`、`:287`；`[L]preference/ArrowPreference.kt:119`；`[L]theme/Colors.kt:380`、`:490` |
| 禁用（`enabled=false`） | `disabledOnSecondaryVariant` **#B2B2B2 / #707170** | 同左 | 同左 | **否**（`clickable` 被移除） | `[L]basic/Component.kt:274`、`:288`、`:147`；`[L]preference/ArrowPreference.kt:120`；`[L]theme/Colors.kt:364`、`:474` |

### 7. 图标
`MiuixIcons.Basic.ArrowRight`，尺寸 **10dp × 16dp**，RTL 时 `scaleX = -1f` 镜像，`contentDescription = null`（纯装饰）：`[L]preference/ArrowPreference.kt:100-110`。

## 5. SuperIcon → 真实件 `Icon`

### 1. 结构

```
Icon(imageVector|bitmap|painter, tint)
└─ Box(defaultSizeFor(painter) → paint(colorFilter) → semantics(Role.Image))
```
`[L]basic/Icon.kt:155-161`。

### 2. 文本
未使用（图标无文字，`contentDescription` 只进无障碍语义，`:146-154`）。

### 3. 间距
- 默认尺寸 **24dp**，且**只在 painter 没有内在尺寸时**才生效：`[L]basic/Icon.kt:198-204`（`DefaultIconSizeModifier = Modifier.size(24.dp)` 在 `:204`）。
- 有内在尺寸的矢量（如 `ArrowRight` 10×16dp、Material Rounded 系列 24dp）**按内在尺寸渲染**，不受上面那条影响。
- 图标与文字的间距由调用方给：设置页 `padding(end = 6.dp)`（`[S]ui/screen/settings/SettingsMiuix.kt:129`），模块卡图标与文字间 `spacedBy(2.dp)` / `padding(start = 4.dp, end = 3.dp)`（`[S]ui/screen/module/ModuleMiuix.kt:1017`、`:1026`）。

### 4. 组件
`Icon` 是最底层原语，不组合别的库件；tint 默认读 `LocalContentColor`（`[L]basic/Icon.kt:57`）。SukiSU 在主题层把 `LocalContentColor` 固定成 `onBackground`：`LocalContentColor provides MiuixTheme.colorScheme.onBackground`（`[S]ui/theme/MiuixTheme.kt:84-86`）。

### 5. 交互
未使用（`Icon` 无手势；需要可点用 `IconButton`，`[L]basic/IconButton.kt:40`）。

### 6. 状态取值
| 状态 | 颜色 | 依据 |
|---|---|---|
| 正常 | `LocalContentColor`（SukiSU = `onBackground` #000000 / #E6FFFFFF） | `[L]basic/Icon.kt:57`；`[S]ui/theme/MiuixTheme.kt:85` |
| 强调 / 危险 | 由调用方显式传 `tint` | 例：模块卡 `actionIconTint` = `onSurface.copy(alpha = 0.9f)`（亮）/ `0.7f`（暗）→ 亮 #000000@90% / 暗 #F2F2F2@70%（`[S]ui/screen/module/ModuleMiuix.kt:773`） |
| 禁用 | **库无 `enabled` 概念**，只能由调用方把 tint 换成禁用色 | `[L]basic/Icon.kt:53-58`（无 enabled 参数） |

### 7. 图标
- 模块卡混用两套图标集：Material `Icons.Rounded.PlayArrow`（24dp，`[S]ui/screen/module/ModuleMiuix.kt:947-952`）、`Icons.Rounded.Code`（22dp，`:979-984`）；Miuix `MiuixIcons.UploadCloud`（20dp，`:1019-1024`）、`MiuixIcons.Delete` / `MiuixIcons.Undo`（20dp，`:1053-1062`）。导入见 `[S]ui/screen/module/ModuleMiuix.kt:59-62`、`:146-151`。
- 自绘图标：SukiSU 只有 `AppIconImage`（应用图标，目标 48dp + 150ms 交叉淡入：`[S]ui/component/AppIconImage.kt:41`、`:72`）。

### 7.5 点击反馈到底是什么（需求书 §4.4 最后一条）

**结论：既不是 Material ripple，也不是 sink 缩放，而是 Miuix 自有的一层"矩形叠层"（MiuixIndication）。**

| 证据点 | 内容 | 位置 |
|---|---|---|
| 主题注入 | `LocalIndication provides miuixIndication` | `[L]theme/MiuixTheme.kt:32-36`（`:61-65` 暗色分支同） |
| 行的点击 | `Modifier.clickable(interactionSource, onClickLabel, role, onClick)` —— 不传 `indication`，落回 `LocalIndication` | `[L]basic/Component.kt:148-153` |
| 叠层形状 | 全尺寸 `drawRect(color, alpha, size)`，**矩形、自身无圆角、无波纹扩散**；但**在 Card 内会被父级 squircle 遮罩抠掉四角**（`[L]basic/Card.kt:177` + `[L]squircle/SquircleBackground.kt:255-288`），视觉上等于跟随卡片圆角——勘误：原写「无圆角裁剪」，漏了这层父级遮罩 | `[L]utils/MiuixIndication.kt:129-133`；类注释 "draws a rectangular overlay" `:36` |
| 叠层透明度 | 按压 **+0.10**、悬停 **+0.06**、聚焦 **+0.08**、长按保持 **+0.10** | `[L]utils/MiuixIndication.kt:25-28`、`:66-73` |
| 叠层色 | `MiuixTheme.colorScheme.onBackground` | `[L]theme/MiuixTheme.kt:32` |
| 动画 | folme spring，按下 damping 1.0/response 0.2，抬起 0.95/0.35 | `[L]utils/MiuixIndication.kt:30-33` |
| 对比：sink 缩放 | `SinkFeedback(sinkAmount = 0.94f, spring(0.8f, 600f))`，**只有显式传 `PressFeedbackType.Sink` 的组件才有**（`Card` / `Button`） | `[L]utils/PressFeedback.kt:31-33`；`[L]basic/Card.kt:105-111` |

因此：**设置页三种行按下时 = 整行蒙一层 10% 的 `onBackground`，无扩散波纹、无缩放。**

### 8.1 两条"别照抄"的提醒

1. **不要给卡片加 disabled 暗化**——SukiSU 模块卡关闭时不改底色（`:783-797`）；作者现在的做法属于自创。
2. **不要给行加 ripple**——库的按压反馈是 `MiuixIndication` 矩形叠层；自己写 `clickable` 不传 `indication` 就会自动继承（前提是在 `MiuixTheme { }` 内），不必引入 Material ripple。

## 10. 未确证清单（不许当铁律）

1. **真机默认色彩模式到底走哪条分支**：代码默认 `themeMode = 0`（`[S]data/repository/SettingsRepositoryImpl.kt:73-75`）、`miuixMonet = false`（`:77-79`）、`keyColor = 0`（`:81-83`）；`ColorMode.fromValue(0) = SYSTEM`（`[S]ui/theme/Theme.kt:14-22`）→ `ThemeController(colorSchemeMode = System, keyColor = null)`（`[S]ui/theme/MiuixTheme.kt:58-71`）→ `lightColors/darkColors` 静态调色板（`[L]theme/ThemeController.kt:235-243`）。**所以默认状态下 §2–§7 给的字面值是准的**；但只要用户把色彩模式改成 `MONET_*` 或设了自定义 keyColor，颜色立刻变成 `colorsFromSeed` / `platformDynamicColors` 运行时派生（`[L]theme/ThemeController.kt:245-262`）——此时"无静态值"，只能用变量名。用户实际选择无法从源码判定，所以两套并列给出。
2. `module.remove = true` 之后开关是否仍可切换：代码里 `Switch(enabled = !module.update)`（`[S]ui/screen/module/ModuleMiuix.kt:894`）不排除 `remove` 状态，理论上仍可点，但 ksud 侧对已标记卸载的模块如何处理未验证 → **未确证**。
3. 模块卡带 banner 时的最终底色：`Modifier.moduleBanner(banner, scrim = surfaceContainer)`（`[S]ui/screen/module/ModuleMiuix.kt:795`、`[S]ui/screen/module/ModuleBanner.kt:53`）如何叠加 scrim 未逐行推算 → **未确证**（无 banner 的模块就是 `surfaceContainer` 纯色）。
4. `MiuixIndication` 的矩形叠层画在 `Card` 上时是否被 squircle 裁剪：`Card` 的可点重载把 `combinedClickable` 挂在内容 `Column` 上（`[L]basic/Card.kt:145-148`），而不是挂在外层 squircle 容器；SukiSU 的组卡都没用 `showIndication`，所以没有实机样本 → **未确证**（`BasicComponent` 行内确证是矩形，见 §7.5）。
