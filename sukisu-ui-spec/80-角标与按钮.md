### 1.2 位置偏移：`BadgedBox` 的定位数学

`BadgedBox(badge, content)` 用两段子项「anchor」+「badge」做自定义 `Layout`（`Badge.kt:51-117`）：

| 量 | 无内容（6dp 圆点） | 有内容（≥16dp） | 位置 |
|---|---|---|---|
| 是否算"有内容" | badgeWidth ≤ Size | badgeWidth > Size | `Badge.kt:93` |
| 水平偏移 | **6dp**（`BadgeOffset`） | **12dp**（`BadgeWithContentHorizontalOffset`） | `Badge.kt:94-95`、`:226`、`:233` |
| 垂直偏移 | **6dp**（同一个 `BadgeOffset`） | **14dp**（`BadgeWithContentVerticalOffset`） | `Badge.kt:96-97`、`:227` |
| X 落点 | min(anchorW − 6dp, 容器右边界 − badgeW) | min(anchorW − 12dp, 容器右边界 − badgeW) | `Badge.kt:102-106` |
| Y 落点 | max(−badgeH + 6dp, 容器上边界) | max(−badgeH + 14dp, 容器上边界) | `Badge.kt:108-112` |

人话换算（**有内容 / 16dp 徽章**）：徽章左边缘落在锚点（图标）宽 − 12dp 处 → 右边缘**只探出图标右边 4dp**；垂直方向底边压到图标顶边下 14dp → 顶边**探出图标上边 2dp**。也就是"压在图标右上角、往里缩"，而不是整个挂在外面。
（**6dp 圆点**）：圆心落在图标右上角内侧 6dp，即一半在外、一半在内。

**必须配套的一步**：父级（导航项）要挂 `Modifier.badgeBounds()`，它给布局注册"右边界 = 自身宽、上边界 = 0"两条 ruler（`Badge.kt:238-252`），上面的 min/max 才夹得住角标。库内两处已经挂好：`NavigationBarItem`（`[L]basic/NavigationBar.kt:175`）、`FloatingNavigationBarItem`（`:402`）。**自己实现时必须一起加**，否则角标会跑出条目外。

### 1.4 容器的两种 tone（**这是"error 还是 primary"的正式答案**）

`navigationBadgeFor` 按 `BadgeTone` 分两支（`BottomBarMiuix.kt:145-171`）：

| tone | 触发条件 | 容器色 | 内容色 | 依据 |
|---|---|---|---|---|
| `Alert` | **模块页**：moduleUpdatableCount > 0 | **不传参** → `BadgeDefaults.containerColor` = **`error`** #E94634 / #F12522 | `onError` #FFFFFF / #FFFFFF | `BottomBarMiuix.kt:152-158`；`[S]ui/component/bottombar/BottomBar.kt:98-99` |
| `Accent`（停靠） | 超级用户：superuserCount > 0；模块页：无更新但 moduleEnabledCount > 0 | **`primary`** #3482FF / #277AF7 | `onPrimary` #FFFFFF | `BottomBarMiuix.kt:160-169`；`BottomBar.kt:94-105` |
| `Accent`（浮台） | 同上，floating = true | **`primaryContainer`** #5D9BFF / #338FE4 | `onPrimaryContainer` #FFFFFF | `BottomBarMiuix.kt:109`、`:163-164` |

**结论**：`Badge` 的**默认**容器色是 `error`（`Badge.kt:188-189`）；SukiSU 只在 `Accent` 分支显式改成 `primary` / `primaryContainer`。所以"角标是红还是蓝"取决于业务：**模块待更新 = 红（error）**，其余计数 = 蓝（primary，浮台上是 primaryContainer）。

### 1.5 计数来源与总开关

- `NavigationBadgeState(superuserCount, moduleEnabledCount, moduleUpdatableCount)`（`BottomBar.kt:82-87`）。
- 取值：superuserCount = 内核 allowlist 里的授权数（`[S]ui/MainActivity.kt:357-361`）；moduleEnabledCount = `modules.count { it.enabled }`；moduleUpdatableCount = `updateInfo.count { it.value.downloadUrl.isNotBlank() }`（`:363-368`）。
- 总开关：`badgeEnabled = 设置项 且 Natives.isFullFeatured()`（`:318-319`），关闭时传空 `NavigationBadgeState()`（`:369-371`）；设置项默认 true（`[S]data/repository/SettingsRepositoryImpl.kt:117-119`）。
- 优先级：模块项**每项只显示一个**角标，`when` 先判"可更新"再判"已启用"（`BottomBar.kt:98-105`）→ 有更新显示更新数（红），否则显示启用数（蓝），都为 0 则 **返回 null → 不画角标**（`BottomBarMiuix.kt:150`）。

### 1.7 七项（`Badge` 本体）
1. **结构**：`BadgedBox → [Box(anchor) = Icon, Box(badge) = Badge → Row → Text]`（`Badge.kt:56-65`、`:143-177`）。
2. **文本**：数字（`count.toString()`）｜**11sp**｜默认字重｜`contentColor` = `onError`（Alert）/ `onPrimary`、`onPrimaryContainer`（Accent）。
3. **间距**：圆点 6dp；带内容最小 16dp + 水平 4dp 内边距；偏移见 §1.2。
4. **组件**：`BadgedBox`（定位）+ `Badge`（外观）；刻意不用 `Surface`，避免拦截下层点击（注释 `Badge.kt:159`）。
5. **交互**：**不可点、不消费触摸**（纯 `Row` + `background`，`Badge.kt:143-157`）；点击落到下层导航项。
6. **状态取值**：`Alert`（error 底 / onError 字）/ `Accent`（primary 或 primaryContainer 底 / 对应 on 色）；数量为 0 时**整体不渲染**。
7. **图标**：无（纯数字）。要做"只红点"：`Badge { }` 不给 content → 6dp 圆点。

### 3.2 模块页 FAB 七项

1. **结构**：`Scaffold(floatingActionButton = { if (installButtonVisible) FloatingActionButton(...) { Icon } })`（`ModuleMiuix.kt:357-421`）→ 库 `FloatingActionButton` = `Surface(onClick) { Box(defaultMinSize(60×60), Center) { content } }`（`[L]basic/FloatingActionButton.kt:46-63`）。
2. **文本**：无可见文字（只有图标；但传了 `contentDescription = R.string.module_install`，`ModuleMiuix.kt:412-414`）。
3. **间距 / 尺寸**：
   - 库最小尺寸 **60dp × 60dp**（`FloatingActionButtonDefaults.MinWidth/MinHeight`，`FloatingActionButton.kt:69`、`:72`）；
   - 形状 `CircleShape`（`:39`）；容器色 `primary`（#3482FF / #277AF7，`:40`）；
   - 图标 `Modifier.size(40.dp)`、`tint = onPrimary`（`ModuleMiuix.kt:412-417`）；
   - **阴影被显式关掉**：`shadowElevation = 0.dp`（`ModuleMiuix.kt:402`），库默认 **4dp**（`FloatingActionButton.kt:75`）；
   - **改成 0.05dp 描边**：`border(0.05.dp, outline@0.5, CircleShape)`（`ModuleMiuix.kt:401`；`outline` #D9D9D9 / #404040）。
4. **组件**：`FloatingActionButton`（库件）+ `Surface` + `Icon`（Material `Icons.Rounded.Add`）。
5. **位置**（三段叠加）：
   - `Scaffold` 默认 `FabPosition.End`（`[L]basic/Scaffold.kt:84`）：`x = layoutWidth − FabSpacing(12dp) − fabWidth`（`:236`；`FabSpacing = 12.dp` 在 `:460`）；
   - FAB 自身 `padding(bottom = bottomInnerPadding + 20dp, end = 20dp)`（`ModuleMiuix.kt:400`）；
   - 垂直：`y = layoutHeight − (fabHeight + 12dp + contentWindowInsets.bottom)`（`Scaffold.kt:256-264`、`:371`），本页 `contentWindowInsets` 只留 Horizontal → 该 inset = 0（`ModuleMiuix.kt:457`）。
   - **净结果**：圆形右边缘距屏幕右 **32dp**（12 + 20）；下边缘距页面底 **12dp + bottomInnerPadding + 20dp**（bottomInnerPadding = 外层底栏高度，见 `30-模块.md §1.0`）。
6. **状态取值**：正常 = `primary` 底 + `onPrimary` 图标 + 0.05dp 半透明描边 + **无阴影**；按下 = 见 §3.3；不可见 = `if (installButtonVisible)` 整体不组合（`:358`），**没有"禁用态"外观**。
7. **图标**：`Icons.Rounded.Add`，**40dp**，`tint = onPrimary`（`ModuleMiuix.kt:412-417`）。

### 3.3 点击动画到底是什么

- FAB 没有任何缩放/位移/抬升动画：`FloatingActionButton` 只是把 `onClick` 转交给 `Surface(onClick)`（`[L]basic/FloatingActionButton.kt:46-53`），`Surface` 内部是 `Modifier.clickable(interactionSource, indication = LocalIndication.current, …)`（`[L]basic/Surface.kt:88-119`）。
- `LocalIndication` 在 MiuixTheme 里被替换成 `MiuixIndication(color = onBackground)`（`[L]theme/MiuixTheme.kt:32-36`，暗色分支 `:61-65`）。
- 所以按下 = **在圆内蒙一层 onBackground 矩形叠层**（`drawRect(color, alpha, size)`，`[L]utils/MiuixIndication.kt:129-135`；外层 `clip(CircleShape)` 把它裁成圆，`Surface.kt:145-146`）：
  - 透明度：**按压 +0.10**、悬停 +0.06、聚焦 +0.08、长按保持 +0.10（`MiuixIndication.kt:25-28`、`:66-73`）；
  - 进/出曲线：**`folmeSpring(damping = 1.0, response = 0.2)`** 进入、**`folmeSpring(damping = 0.95, response = 0.35)`** 退出（`:30-31`）；
  - **不是** Material ripple 波纹，**也不是** `PressFeedbackType.Sink` 的 0.94 缩放（后者只有 `Card`/`Button` 显式传参才有，`[L]utils/PressFeedback.kt:31-33`）。
- 阴影在按压时**不变**（SukiSU 已设为 0）。
