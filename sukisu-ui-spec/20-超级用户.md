# 20 · 超级用户（SuperUser）

> 对象：SukiSU Ultra v4.2.1 的 `SuperUserPagerMiuix` 与它的二级页 `AppProfileScreenMiuix`。
> **最重要的一条**：列表行里**没有任何开关/下拉控件**——「权限等级」在列表里是**只读的 `StatusTag` 标签**，可交互控件全在点进去的二级页（`SwitchPreference` + `OverlayDropdownPreference`）。需求书 §4.2「行的开关是 Switch 还是 SuperSwitch」的答案是：**都不是，列表里没有开关**；`SuperSwitch` 在 v4.2.1 **不存在**。

## 3. ② 权限等级控件到底是什么

### 3.1 结论（三句话）

1. **列表行里没有控件**：`GroupItem` 的 `Card` 只有 `onClick` / `onLongPress` 两个交互参数，行内唯一的「等级信息」是右端只读的 `StatusTag`（`:550-610`）。
2. **不是 `OverlayDropdownPreference`，也不是自绘 pill**：`OverlayDropdownPreference` 在整个超级用户目录里**一处也没有**（全项目使用点见下），标签是 `Box + Text` 的纯展示件。
3. **可交互的权限控制在二级页**，由两个部件组成：`SwitchPreference`（授不授权）+ `OverlayDropdownPreference`（默认/模板/自定义配置）。

`OverlayDropdownPreference` 在 v4.2.1 的全部使用点（19 处，无一处属超级用户列表）：`ui/screen/sulog/SulogMiuix.kt:327`、`ui/screen/install/InstallMiuix.kt:197`、`ui/screen/colorpalette/ColorPaletteScreenMiuix.kt:227/249/267/401`、`ui/screen/susfs/content/miuix/BasicSettingsContentMiuix.kt:106`、`ui/screen/susfs/component/miuix/UniversalDialogMiuix.kt:107`、`ui/screen/appprofile/AppProfileMiuix.kt:604`、`ui/screen/settings/SettingsMiuix.kt:160/180/349`、`ui/screen/settings/tools/ToolsScreenMiuix.kt:294`、`ui/component/profile/RootProfileConfigMiuix.kt:256`、`ui/component/profile/TemplateConfigMiuix.kt:54`。

### 3.2 二级页里的两个控件（参数给全）

**A. 授权开关 = `SwitchPreference`**（`AppProfileMiuix.kt:306-327`）

| 参数 | SukiSU 传的值 | 出处 |
|---|---|---|
| `startAction` | `Icon(Icons.Rounded.Security)`，`padding(end = 6.dp)`，tint `onBackground` | `:314-321` |
| `title` | `R.string.superuser`（「超级用户」） | `:322` |
| `checked` | `isRootGranted = !isSpecialApp && profile.allowSu` | `:190`、`:323` |
| `onCheckedChange` | `onProfileChange(profile.copy(allowSu = it))` | `:324` |
| 外层 | 单独一张 `Card`（左右 12 dp、下 12 dp）；`isSpecialApp` 时整卡不渲染 | `:307-312`、`:306` |
| 库签名 | `SwitchPreference(checked, onCheckedChange, title, summary = null, startAction, endActions, enabled = true, …)` | `miuix preference/SwitchPreference.kt:45-59` |

**B. 配置模式下拉 = `OverlayDropdownPreference`**（`AppProfileMiuix.kt:569-619`）

| 参数 | 值 | 出处 |
|---|---|---|
| `title` | `R.string.profile`（「配置」/ Profile） | `:605` |
| `items` | `["默认"]` + 可选 `"模板"` + `"自定义"`（有无模板决定第二项） | `:575-587` |
| `selectedIndex` | `modesAndTitles.indexOfFirst { it.first == mode };` 非法时兜底 0 | `:598`、`:615` |
| `startAction` | `Icon(Icons.Rounded.AccountCircle)`，`padding(end = 6.dp)`，tint `onBackground` | `:607-614` |
| 回调 | `onModeChange(modesAndTitles[it].first)`（`onSelectedIndexChange` 的尾随 lambda） | `:616-618` |
| 库签名 | `OverlayDropdownPreference(items: List<String>, selectedIndex: Int, title: String, startAction = null, maxHeight = null, showValue = true, onSelectedIndexChange = null, …)` | `miuix preference/OverlayDropdownPreference.kt:58-75` |

**C. 另有卸载模块开关**（同页）：`SwitchPreference(title = profile_umount_modules, summary = …)`（`ui/component/profile/AppProfileConfigMiuix.kt:35-47`）。

### 3.3 给作者的最小结论

若你的行要「就地改权限等级」——SukiSU **没有这个交互**，照抄只能是：行内显示只读等级标签，点击整行进详情页改。要加就地控件属新增设计，不在 v4.2.1 规格内。

## 8. ⑦ 分组标题到底存不存在

### 8.1 结论：主列表**没有**分组标题

- 主列表就是 `items(uiState.groupedApps)` 直接铺 `GroupItem`，中间没有任何标题行（`:452-479`）。
- 「组」在 SukiSU 里指的是**同 UID 应用簇**（`GroupedApps`，`:452` 的 `key = { it.uid }`），**不是分组标题**——这是需求书最容易误读的一点。
- 视觉上的层次感来自「卡片 + 12 dp 组间距」，不是标题。

### 8.2 全页唯一一个小标题：搜索默认结果的「最近安装」

|---|---|---|
| 文案 | `R.string.recently_installed` | `:309` |
| 字号/字重 | **13 sp / Medium** | `:310-311` |
| 颜色 | `onSurfaceVariantSummary` | `:312` |
| 外边距 | `horizontal 20 dp / vertical 6 dp` + 其上 `Spacer(6.dp)` | `:307`、`:313` |

### 8.3 与 40-设置 的一致性

- **已核对（`40-设置.md` 已交付）**：`40` §2.0 结论与本页一致——设置页同样**没有分组标题**（`SmallTitle` / `HorizontalDivider` 在 `SettingsMiuix.kt` 中 grep 均 0 命中），它同样靠「卡片 + 12dp 上间距」分层。
- 本文的结论只覆盖**超级用户页**：无分组标题。
