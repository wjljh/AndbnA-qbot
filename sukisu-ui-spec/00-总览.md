## 0. 读法约定（先读这 6 行）

1. **路径缩写**
   - SukiSU：省略前缀 `manager/app/src/main/java/com/sukisu/ultra/`，如 `ui/screen/home/HomeMiuix.kt:298`。
   - miuix：省略前缀 `commonMain/top/yukonga/miuix/kmp/`（取自 `miuix-ui-0.9.4-sources.jar`），写作 `miuix theme/Colors.kt:342` 这种形式。
2. **两条平行 UI 支路**：SukiSU 同时维护 Miuix 版（`*Miuix.kt`）与 Material 版（`*Material.kt`），由 `UiMode` 切换（`ui/theme/Theme.kt:110-120`）。**本规格只对齐 Miuix 支路**；Material 支路仅在第 2.3 节出现，用来解释"哪些颜色角色是 Miuix 色板里根本没有的"。
3. **统计口径**：`colorScheme.*` 共 897 处引用。其中 36 个文件用 `import top.yukonga.miuix.kmp.theme.MiuixTheme.colorScheme`（裸写 `colorScheme.xxx`，属 Miuix），55 个文件写 `MaterialTheme.colorScheme.xxx`（属 Material）。本册计数**只算前者**。
4. **颜色双轨**：非 Monet 模式下 miuix 用**内置静态色板**（`miuix theme/Colors.kt:341-504`），有确切 #RRGGBB；Monet 模式下全部改由 keyColor 经 monet 算法派生，**无静态值**。出厂默认是非 Monet（见 1.3），所以下文静态值就是默认外观。
5. **不许猜**：拿不到确切值的写在第 8 节"未确证"，不进正文数值。
6. **许可证**：本文只描述结构与取值，不整段引用 SukiSU 源码（GPL-3.0 边界，需求书 §6）。

## 1. 主题是怎么搭的

### 1.1 入口与分流

| 环节 | 事实 | 出处 |
|---|---|---|
| 应用根主题 | `KernelSUTheme(appSettings, uiMode)` 按 `LocalUiMode` 二分到 `MiuixKernelSUTheme` / `MaterialKernelSUTheme` | `ui/theme/Theme.kt:103-120` |
| 设置读取 | `ThemeController.getAppSettings()` 从 SharedPreferences 读 `themeMode` / `keyColor` / `colorStyle` / `colorSpec`，并按 `uiMode` + `miuixMonet` 平移 `themeMode` | `ui/theme/Theme.kt:67-101` |

### 1.2 `ThemeController` 参数实际传了什么（5 个显式传，`lightColors`/`darkColors` 走库默认）

| 参数 | SukiSU 实传 | 说明 | 出处 |
|---|---|---|---|
| `colorSchemeMode` | `ColorMode` → `ColorSchemeMode` 一一映射：SYSTEM→System、LIGHT→Light、DARK→Dark、MONET_SYSTEM→MonetSystem、MONET_LIGHT→MonetLight、MONET_DARK/DARK_AMOLED→MonetDark | 7 档枚举，AMOLED 复用 MonetDark | SukiSU `ui/theme/MiuixTheme.kt:58-66`、`ui/theme/Theme.kt:14-45` |
| `keyColor` | `resolvedKeyColor: Color?` 四级判定：① `repo.keyColor != 0` → `Color(keyColor)`；② 是 Monet 且 SDK≥31 → 系统 `dynamic{Light,Dark}ColorScheme().primary`；③ 是 Monet 且 SDK<31 → `FallbackSeedColor`；④ 其余 → `null` | 传 `null` 时库内 Monet 分支回落 `platformDynamicColors` | `ui/theme/MiuixTheme.kt:46-56`；库 `miuix theme/ThemeController.kt:229-255` |
| `isDark` | `darkTheme = colorMode.isDark \|\| (colorMode.isSystem && isSystemInDarkTheme())` | 显式传给库，让 System/MonetSystem 也走同一判定 | `ui/theme/MiuixTheme.kt:30`、`ui/theme/Theme.kt:27-29` |
| `paletteStyle` | `ThemePaletteStyle.valueOf(colorStyle.name)`，异常回落 `TonalSpot` | 默认设置值 = `TonalSpot` | `ui/theme/MiuixTheme.kt:34-38`；默认值 `data/repository/SettingsRepositoryImpl.kt:83-85` |
| `colorSpec` | `effectiveFor(paletteStyle)` 后映射：SPEC_2025→`ThemeColorSpec.Spec2025`，否则 `Spec2021` | 只有 TonalSpot/Neutral/Vibrant/Expressive 支持 2025，其余自动降级 | `ui/theme/MiuixTheme.kt:40-44`、`ui/theme/Theme.kt:54-65`；库 `miuix theme/ThemeController.kt:66-81` |
| `lightColors` / `darkColors` | **不传**（吃库默认 `lightColorScheme()` / `darkColorScheme()`） | 这就是 2.1 静态值的来源 | 库 `miuix theme/ThemeController.kt:207-208` |

### 1.3 暗色判定 / 动态取色开关 / 与 MaterialTheme 的关系

- **暗色判定有两套，务必分清**：
  1. 建主题时用 `appSettings.colorMode.isDark` 推理出来的 `darkTheme`（`ui/theme/MiuixTheme.kt:30`）；
  2. 业务代码里用 `isInDarkTheme()`，它读 `LocalColorMode`（Int）再按 1/4=亮、2/5/6=暗、其余跟系统（`ui/theme/Theme.kt:123-131`）。
  → **坑**：写新组件时用 `isInDarkTheme()`，**不要**用 `isSystemInDarkTheme()`——在"强制亮/暗"档下后者是错的。SukiSU 的 hero 卡、标签底都按前者分流（`ui/screen/home/HomeMiuix.kt:277-279`、`ui/screen/superuser/SuperUserMiuix.kt:533-536`）。
- **动态取色（Monet）开关**：设置项 `miuixMonet`（默认 `false`）。它在 `getAppSettings()` 里把 `themeMode` 在非 Monet↔Monet 之间平移（`ui/theme/Theme.kt:72-82`），UI 侧再映射成 `ColorSchemeMode`。**出厂默认 `themeMode=0` + `miuixMonet=false` → `ColorSchemeMode.System` → 静态色板**（`data/repository/SettingsRepositoryImpl.kt:73-78`；库分支 `miuix theme/ThemeController.kt:225-227`）。
- **业务侧怎么知道当前是 Monet**：用库的派生属性 `MiuixTheme.isDynamicColor`，它等价于"当前 mode 是三个 Monet 之一"（库 `miuix theme/MiuixTheme.kt:84-93`）。SukiSU 全站用它决定"用容器色还是硬编码色"（`ui/screen/home/HomeMiuix.kt:300`、`:348`、`:355`；`ui/component/miuix/WarningCard.kt:59-83`）。
- **对 MaterialTheme 有无桥接：没有。** Miuix 支路里不创建 `MaterialTheme`，Material 支路里也不读 Miuix 色板；两者各自算色（`ui/theme/MaterialTheme.kt:27-51`）。唯一的"桥"是给内嵌 WebUI 用的 CSS 变量：`MonetColorsProvider.UpdateCss()` 把 Miuix 角色按 MD3 名字写进 CSS（`ui/webui/MonetColorsProvider.kt:37-80`，注意 `:69-70` 把 `onSurfaceVariant ← onSurfaceVariantSummary`、`outlineVariant ← dividerLine`）。**这解释了为什么 SukiSU 的 Miuix 代码里会"出现" MD3 角色名——那只在 WebUI 用。**
- **仍会提供 `LocalContentColor`**：库自己 provides `onBackground`（`miuix theme/MiuixTheme.kt:37`），SukiSU 又显式 provide 一次（`ui/theme/MiuixTheme.kt:84-88`）——效果相同，但说明"全局默认文字色 = onBackground"。
- **状态栏明暗**：`LaunchedEffect(darkTheme)` 设 `isAppearanceLightStatusBars/NavigationBars = !darkTheme`（`ui/theme/MiuixTheme.kt:76-82`）。

### 2.3 Miuix 色板里**不存在**的角色（你现在可能正在用）

miuix `Colors` 构造参数共 54 个（`miuix theme/Colors.kt:68-122`），**没有** `onSurfaceVariant`、`outlineVariant`、`surfaceTint`、`tertiary`、`onTertiary`、`surfaceBright`、`surfaceDim`、`surfaceContainerLow/Lowest`、`inverseSurface`、`inverseOnSurface`、`inversePrimary`、`scrim`、`surfaceColorAtElevation`。

| 你在用（Material3） | Miuix 0.9.4 对应 | 备注 |

| `onSurfaceVariant`（次要文字） | `onSurfaceVariantSummary` | 语义最接近；60%/50% 黑白色 |

## 7. 全局约定与坑（每条都会改变实现正确性）

### 7.1 主题与颜色

- **C1 主题只走 `MiuixTheme`，没有 MaterialTheme 桥接。** 若要 Material 组件（极少数场景），需另建一层（`ui/theme/MaterialTheme.kt:17-51`），SukiSU 是两个独立支路，不混用。
- **C2 出厂是静态色板，不是 Monet。** `themeMode=0` + `miuixMonet=false`（`data/repository/SettingsRepositoryImpl.kt:73-78`）→ `ColorSchemeMode.System` → 2.1 的字面值。也就是**默认外观可以直接照抄 hex**，Monet 只是可选开关。
- **C3 "是否动态取色"用 `MiuixTheme.isDynamicColor`**（`miuix theme/MiuixTheme.kt:84-93`），不要自己读设置项。
- **C4 暗色判定用 `isInDarkTheme()`**（`ui/theme/Theme.kt:123-131`），不要用 `isSystemInDarkTheme()`（强制档下会错）。
- **C5 无 `onSurfaceVariant`。** Miuix 色板 54 个 field 里没有它（`miuix theme/Colors.kt:68-122`），该名字在 SukiSU 里只属于 Material 支路；替代见 2.3。

### 7.2 布局

- **C6 `Scaffold` 会把 `bottomBar` 高度算进内容 padding。** 内容底部 `contentPadding.bottom = bottomBarPlaceable.height.toDp()`（`miuix basic/Scaffold.kt:325-337`，具体在 `:337`）。**因此不需要再自己加 96 dp 之类的页尾留白**；SukiSU 直接吃 `innerPadding`（`HomeMiuix.kt:179-184`）。
- **C7 `Card` 默认 `insideMargin = 0 dp`**（`miuix basic/Card.kt:195`），内边距必须自己给（写法 A/B 见 4.2）。
- **C8 `contentWindowInsets` 只取横向。** SukiSU 主页写 `WindowInsets.systemBars + displayCutout`，只保留 Horizontal（`HomeMiuix.kt:114` 附近），纵向交给各卡片处理。

### 7.3 文字与图标

- **C9 `textStyles` 无颜色；`Text` 默认 style = `main` 17 sp；默认色 = `LocalContentColor`（Card 内 = `onSurfaceContainer`）。** 见 3.2 三个坑，出处 `miuix theme/TextStyles.kt:146-230`、`miuix basic/Text.kt:108-110`、`miuix basic/Card.kt:170`/`:203`。
- **C10 停靠栏选中态 = 颜色 + Bold，没有 indicator 胶囊。** 库只做 `tint = colors.contentColor(selected, isPressed)` + `fontWeight = if (selected) Bold else Normal`（`miuix basic/NavigationBar.kt:159-160`），选中/未选中同底色（都取 `onSurfaceContainer`，`:474-475`），未选中 alpha 0.4（`:463`）。胶囊只存在于 SukiSU 的液态玻璃分支（`ui/component/FloatingBottomBar.kt`），本次不实施。
- **C11 底栏 label 字号 11 sp 只在浮层实现里写死**（`BottomBarMiuix.kt:123`）；停靠式由库给 12 sp（`miuix basic/NavigationBar.kt:448`）。两者不一致是源码现状，不是笔误。
- **C12 图标库是混用的**：`MiuixIcons` 只用于 Back/Delete/Sort/Refresh 等十几个，其余全是 `Icons.Rounded.*`（见 6.1）。照抄时不要强行统一到 `MiuixIcons`——很多图标 Miuix 没有。

### 7.4 一条反直觉但影响面最大的事实：SukiSU **没有 SuperCard/SuperSwitch/SuperArrow**

需求书 §2 提到的 `SuperCard`、`SuperSwitch`、`SuperArrow`、`SuperIcon` 在 v4.2.1 **全部不存在**（`grep -rl 'SuperCard|SuperSwitch|SuperArrow|SuperIcon' ui/` → 0 命中）。v4.2.1 的做法是**直接使用 miuix 原生组件**：`Card`、`Switch`、`ArrowPreference`、`SwitchPreference`、`BasicComponent`、`TextButton`。自研组件只剩 3 个：`ui/component/miuix/SuperEditArrow.kt`、`SuperSearchBar.kt`、`WarningCard.kt`。
→ **对 andbna 的意义**：`90-组件库.md` 应当写成"如何正确调用 miuix 原生组件"而不是"复刻 SukiSU 的封装层"。

**卡片容器基线（全站复用的容器元素，按七项给出）**

1. **结构**：`Card(colors=defaultColors|自定义 color, insideMargin=..., onClick=..., showIndication=..., pressFeedbackType=Tilt)` → `[Box | Column | Row]` → 内容。结构骨架见 `ModuleMiuix.kt:783-800`、`SuperUserMiuix.kt:550-566`。
2. **文本**：卡内标题 17 sp / Medium 或 550（`ModuleMiuix.kt:856-857`、`HomeMiuix.kt:504-506`）；摘要 12 sp（`ModuleMiuix.kt:878`）或 14 sp（`HomeMiuix.kt:510`）；颜色一律显式给（`onSurface` / `onSurfaceVariantSummary`）。
3. **间距**：外 12 dp 边距 + 12 dp 卡间距；内 16 dp（`ModuleMiuix.kt:796`、`HomeMiuix.kt:545`）；圆角 16 dp（`miuix basic/Card.kt:190`）。
4. **组件**：miuix `Card` + `CardDefaults.defaultColors()`（`miuix basic/Card.kt:201-207`）；无 SukiSU 封装。
5. **交互**：`onClick` 整卡可点；`showIndication` 控制按压水波；`pressFeedbackType = PressFeedbackType.Tilt` 倾斜反馈（`HomeMiuix.kt:288`）；超级用户行另有 `onLongPress`（`SuperUserMiuix.kt:555`）；模块开关无二次确认，卸载/删除有确认对话框。
