## 0. 三套主题是怎么判定的（先看这张，后面所有「三套色」才有意义）

| 概念 | 判定表达式 | 含义 | 出处 |
|---|---|---|---|
| 是否动态色 | MiuixTheme.isDynamicColor | colorSchemeMode ∈ {MonetSystem, MonetLight, MonetDark} 时为 true | miuix:theme/MiuixTheme.kt:85-95 |
| SukiSU 怎么给 colorSchemeMode | ColorMode.MONET_* → Monet*；DARK_AMOLED 也算 MonetDark | 所以「monet 开」⇔ isDynamicColor | ui/theme/MiuixTheme.kt:58-71 |
| monet 的种子色 | keyColor（用户选）或系统 dynamicColorScheme().primary；前者优先 | 所有容器色由此派生 | ui/theme/MiuixTheme.kt:46-56 |
| 是否暗色 | isInDarkTheme() | LocalColorMode ∈ {2,5,6} → 暗；{1,4} → 亮；其它跟随系统 | ui/theme/Theme.kt:123-131 |

**关键结论：在 SukiSU 的所有颜色 when 里，「动态色」永远压过「暗/亮」。** monet 模式下亮/暗那两档字面值根本走不到。

## 4. 「状态 → 颜色」是怎么算的：判定顺序与优先级

### 4.1 hero 卡底色（HomeMiuix.kt:276-280）

~~~
when {
    isDynamicColor      -> colorScheme.secondaryContainer   // 第 1 优先，monet 亮/暗都走这里
    isInDarkTheme()     -> Color(0xFF1A3825)                // 只在非 monet 时可达
    else                -> Color(0xFFDFFAE4)                // 非 monet 亮色
}
~~~

- **优先级：动态色 > 暗 > 亮**。因为第一条一旦命中就直接返回，与 isInDarkTheme 无关。
- 结果：monet 用户无论亮暗，hero 都是 secondaryContainer；两档字面绿只服务「非 monet」用户。

### 4.2 大对勾 tint（HomeMiuix.kt:300-304）

~~~
if (isDynamicColor) colorScheme.primary.copy(alpha = 0.8f) else Color(0xFF36D167)
~~~

- **只有动态/非动态两档，没有暗色分支**——所以暗色模式（非 monet）下的对勾依旧是 #36D167 亮绿，压在 #1A3825 深绿底上。

### 4.3 StatusTag「自定义」双色（HomeMiuix.kt:348-361）

| 部位 | 动态 | 暗 | 亮 |
|---|---|---|---|
| 文字 contentColor | colorScheme.onTertiaryContainer | #B8E8C5 | #164A29 |
| 背景 backgroundColor | colorScheme.tertiaryContainer | #315D3E | #B8E8C5 |

顺序同样是 **动态 > 暗 > 亮**（每条独立 when）。

### 4.4 卡内文字为什么「没有自己的颜色」

Text 不传 color ⇒ 取 LocalContentColor（miuix:basic/Text.kt:110）；Card 把 LocalContentColor 设成 CardColors.contentColor（miuix:basic/Card.kt:169-171）；而 hero 只传了 color、没传 contentColor ⇒ **contentColor 取默认 onSurfaceContainer**（miuix:basic/Card.kt:201-209）。

→ 所以 H1 里所有未显式传色的字（主标题、版本行、Built-in/LKM）都是 **onSurfaceContainer**：亮 **#000000**、暗 **#E6FFFFFF**、动态由 keyColor 派生。

→ 反例（H2/H3）：那里的标题/副标题走的是 **BasicComponent 的显式颜色**，不看 LocalContentColor：标题 onBackground、副标题 onSurfaceVariantSummary（miuix:basic/Component.kt:90-103、:273、:287）。所以同一张 surfaceContainer 卡上，H1 用 onSurfaceContainer、H2/H3 用 onBackground，值恰好接近但不是同一个变量。

### 4.5 WarningCard 的 when（ui/component/miuix/WarningCard.kt:57-84）

| 部位 | 优先级 1：isDynamicColor | 优先级 2：isInDarkTheme() | 优先级 3：else（亮） |
|---|---|---|---|
| 底色 Error | colorScheme.errorContainer | **#310808** | **#F8E2E2** |
| 底色 Notice | colorScheme.tertiaryContainer | **#3E2F1B** | **#FFF0DB** |
| 文字 Error | colorScheme.onErrorContainer | **#F72727**（暗亮同值！） | **#F72727** |
| 文字 Notice | colorScheme.onTertiaryContainer | **#F5A623**（暗亮同值！） | **#F5A623** |

⚠️ 注意文字色那个 when **只判 isDynamicColor**，没有暗色分支（WarningCard.kt:75-84）——暗色下是用亮色红字 #F72727 压在 #310808 深红底上，作者就是这么写的。照着抄时别自作聪明加暗色分支，否则和原版不像。
