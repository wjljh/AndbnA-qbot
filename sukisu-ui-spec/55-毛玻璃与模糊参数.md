# 55 · 毛玻璃与模糊参数（miuix-blur 0.9.4 实解包）

> **一句话结论**：miuix `0.9.4` 的模糊全部在独立 artifact **`top.yukonga.miuix.kmp:miuix-blur-android:0.9.4`** 里（`miuix-ui` 的 pom **不**依赖它），AAR manifest 写死 **`minSdkVersion=33`**；SukiSU 的「顶栏/停靠底栏毛玻璃」= 自家 `BlurredBar` 包一层 `Modifier.textureBlur(blurRadius = 25f dp, tint = surface@87%)`，浮层玻璃 = `drawBackdrop { vibrancy(); blur(4.dp); lens(24.dp, 24.dp) }` + `surfaceContainer@40%`，其中 `vibrancy` / `lens` **是 SukiSU 自研**（`[S]ui/component/liquid/`），不是库 API。

## 3. 数值落地

### 3.1 半径 → σ → 降采样档 → padding（全部源码常量）

| 量 | 值 | 出处 |
|---|---|---|
| 半径→σ 系数 | **0.45**（`BLUR_RADIUS_TO_SIGMA`） | `[L]blur/internal/BlurEffect.kt:22` |
| 卷积核半径 | **13** px（`BLUR_KERNEL_REACH`，即 -13..+13 共 27 tap） | `[L]blur/internal/BlurEffect.kt:28`；`:533-535` 注释 |
| 实际采样 tap 上限 | **7**（`MAX_BLUR_TAPS`，27 tap 两两线性合并进 7 槽） | `[L]blur/internal/Shaders.kt:32`；`[L]blur/internal/BlurEffect.kt:541+` |
| 降采样档位表 `downScaleExpFor(σ²)` | `σ² >= 1945 → 4`；`> 400 → 3`；`>= 90.25 → 2`；`>= 12.6 → 1`；否则 `0` | `[L]blur/internal/BlurEffect.kt:487-494` |
| 各档「隐含盒式方差」补偿 | `[0f, 3.0265f, 7.5625f, 9.0f, 202.696f]`；`adjustedVariance = (σ² − box) / ds²`，下限 `0.1` | `:484`、`:496-499` |
| 跨档交叉淡入 | 边界 σ = `[3.5496478, 9.5, 20, 44.10215]`；带宽 **±12%**（`BLEND_BAND_FRACTION = 0.12f`），smoothstep 混合 | `:508`、`:510-531` |
| padding | `13 << exp` px（`blur` 内自动抬） | `[L]blur/BackdropEffects.kt:67-70` |
| 渐变模糊 tap 上限 | **24**（`PROGRESSIVE_BLUR_MAX_TAP`） | `[L]blur/internal/Shaders.kt:40` |
| 渐变三级权重 | `1.0 / 0.4 / 0.13`（`PROGRESSIVE_LEVEL_FRACTION_0/1/2`） | `:162-164` |

**换算（算术推算，非文档数字）**：`σ = radius_px × 0.45`，`radius_px = radius_dp × density`。

| 档位 exp | 触发 σ² | 触发 σ | 触发 radius(px) | @density 3.0 (dp) | @density 2.625 (dp) | 降采样 |
|---|---|---|---|---|---|---|
| 0 | < 12.6 | < 3.550 | < 7.89 px | < 2.63 dp | < 3.01 dp | 1× |
| 1 | ≥ 12.6 | ≥ 3.550 | ≥ 7.89 px | ≥ 2.63 dp | ≥ 3.01 dp | 2× |
| 2 | ≥ 90.25 | ≥ 9.5 | ≥ 21.11 px | ≥ 7.04 dp | ≥ 8.04 dp | 4× |
| 3 | > 400 | > 20 | > 44.44 px | > 14.81 dp | > 16.93 dp | 8× |
| 4 | ≥ 1945 | ≥ 44.10 | ≥ 98.01 px | ≥ 32.67 dp | ≥ 37.34 dp | 16× |

> 也就是说**常规 20–25 dp 顶栏模糊在 ξhdpi 上就落进 8× 降采样档**（padding 104 px），这既是性能来源，也是「大半径不糊成块」的补偿来源。

### 3.4 噪声阈值效应（容易踩的默认值坑）

| 常量 | 值 | 含义 | 出处 |
|---|---|---|---|
| `NOISE_GRAIN_THRESHOLD` | `0.005f` | `noiseCoefficient <= 0.005` 时**跳过全分辨率噪声 pass**，只留降采样层内的 anti-banding dither | `[L]blur/DrawBackdropModifier.kt:68-72` |
| `STACK_DITHER_MAX` | `0.009f` | 降采样层的抖动上限（≈1 LSB） | `:64-66` |

> 因默认 `NoiseCoefficient = 0.0045f` **低于** 0.005 阈值：`textureBlur()` 默认配置**不会**走全分辨率噪声，只吃 stack dither。要让颗粒可见必须显式传 ≥0.005（SukiSU 没传，用的是默认 0.0045）。

### 3.5 暗色下的默认差异

- 库侧：**没有任何 `isDark` / `LocalIsDark` 分支**（`blur` 包内 grep 无命中）；`Highlight.Default` 硬绑定亮色预设 `GlassStrokeMiddleLight`（`[L]blur/highlight/Highlight.kt:58`），暗色需自己换 `GlassStroke*Dark`。
- 应用侧：暗色差异全部经由 `MiuixTheme.colorScheme.surface` / `surfaceContainer` 传进来（`[S]ui/util/BlurExt.kt:18`、`[S]ui/component/FloatingBottomBar.kt:220`）→ 亮色是「白底 87% 压暗」，暗色是「黑底 87% 提亮」，tint 语义正好相反，所以**同一个 alpha 在两种模式下观感不对称**，这是设计如此而非 bug。
- SukiSU 还有一处暗色专属：浮层阴影 `dropShadow(radius = 10.dp, alpha = if (isInDark) 0.2f else 0.1f)`（`[S]ui/component/FloatingBottomBar.kt:347-353`）。

### 4.2 两段真实传参（唯一有数值的两处）

1. **静态栏（顶栏 + 停靠底栏）**：`[S]ui/util/BlurExt.kt:33-42`
   - `textureBlur(backdrop, shape = RectangleShape, blurRadius = 25f, colors = BlurColors(blendColors = listOf(BlendColorEntry(MiuixTheme.colorScheme.surface.copy(0.87f)))))`
   - 换算：25 dp → `σ = 25×density×0.45`；density 3.0 时 σ=33.75、σ²≈1139 → **exp 3（8× 降采样）**、padding 104 px。`noiseCoefficient` 走默认 0.0045 → 见 §3.4。
   - `shape = RectangleShape`：栏是直角矩形的，**不做圆角裁剪**；边缘也不加 `Highlight`（`highlight` 未传 → 无描边）。
2. **浮层玻璃（`FloatingBottomBar`）**：`[S]ui/component/FloatingBottomBar.kt:357-377`
   - `drawBackdrop(backdrop, shape = { CircleShape }, effects = { padding = maxOf(padding, 40.dp.toPx()); vibrancy(); blur(4.dp.toPx(), 4.dp.toPx()); lens(refractionHeight = 24.dp.toPx(), refractionAmount = 24.dp.toPx()) }, highlight = { baseHighlight.value.copy(alpha = 0.75f) }, onDrawSurface = { drawRect(containerColor) })`
   - **`blur()` 收 px**：这里写的是 `4.dp.toPx()`，density 3.0 → 12 px → σ=5.4、σ²≈29 → **exp 1（2×）**、padding 26 px；随后 `lens` 把 padding 抬到 `max(26, 72)` = 72 px（`refractionAmount = 24.dp.toPx() = 72 px`）。
   - 胶囊指示器另有第三层：`lens(refractionHeight = 10.dp.toPx()×progress, refractionAmount = 14.dp.toPx()×progress, depthEffect = true, chromaticAberration = 0.5f)`（`[S]ui/component/FloatingBottomBar.kt:442-455`）。

## 5. 给 andbnA 的移植清单

### 5.1 依赖与前置

1. `build.gradle.kts`：`implementation("top.yukonga.miuix.kmp:miuix-blur-android:0.9.4")`（**必须显式加**，`miuix-ui` 不带）。
2. `minSdk` 必须 ≥ **33**。低于 33 时 AAR 的 `<uses-sdk minSdkVersion="33">` 会触发 manifest merger 冲突；若不想抬 minSdk，就需要 `tools:overrideLibrary` + 运行时 `isRuntimeShaderSupported()` 兜底，但**效果在 31/32 上是完全关掉的**（每个效果函数首行就 return）。

### 5.3 最小调用骨架（12 行，顶栏毛玻璃）

```kotlin
@Composable
fun GlassTopBar(enable: Boolean, content: @Composable (Color) -> Unit) {
    val backdrop = if (enable && isRenderEffectSupported())
        rememberLayerBackdrop { drawRect(MiuixTheme.colorScheme.surface); drawContent() }
    else null
    val barColor = if (backdrop != null) Color.Transparent else MiuixTheme.colorScheme.surface
    Box(if (backdrop != null) Modifier.textureBlur(backdrop, RectangleShape, 25f,
        colors = BlurColors(listOf(BlendColorEntry(MiuixTheme.colorScheme.surface.copy(0.87f)))))
        else Modifier) { content(barColor) }
}
// 调用方：Box(Modifier.layerBackdrop(backdrop)) { LazyColumn { … } } —— 漏了这行 backdrop 就是空的
```

### 5.4 常见坑（每条都有源码依据）

| # | 坑 | 依据 |
|---|---|---|
| 1 | **`blur()` 吃 px、`textureBlur(blurRadius=)` 吃 dp**。在 `drawBackdrop { effects = { blur(...) } }` 里写裸数字 20f 等于 20 px（≈6.7 dp），会糊得远不够 | `[L]blur/BackdropEffects.kt:43-46`（`@param radiusX ... in pixels`）vs `[L]blur/TextureEffect.kt:19`（`in dp`） |
| 2 | **`Transparent` 栏色 + 分隔线冲突**：`NavigationBar(showDivider = true)` 是**库默认**，SukiSU 没覆盖 → 透明底上仍画一条 `dividerLine` 细线（厚 0.75 dp）。想要「纯玻璃无缝」必须显式 `showDivider = false` | `[L]basic/NavigationBar.kt:76-77`、`:95-97`；`[L]basic/Divider.kt:71`、`:76`；SukiSU 只传 color `[S]ui/component/bottombar/BottomBarMiuix.kt:65-67` |
| 3 | **忘了 `Modifier.layerBackdrop(backdrop)`**：`LayerBackdrop.drawBackdrop` 在 `coordinates`/`layerCoordinates` 为 null 时**直接 return**，屏幕上只剩 tint 一块纯色 | `[L]blur/LayerBackdrop.kt:80-81`；挂载点 `[S]ui/screen/home/HomeMiuix.kt:116` |
| 4 | **backdrop 的 `onDraw` 要先铺不透明底**（`drawRect(surface)` 再 `drawContent()`），否则半透明 tint 叠空层 → 发灰/透黑 | `[S]ui/util/BlurExt.kt:19-22` |

| 10 | **`padding` 只能调大**；且必须在读完最终 padding 之后的 pass 里才稳定（`blur` 内部会重跑一次 effects 块） | `[L]blur/BackdropEffectScope.kt:30-35`；`[L]blur/BackdropEffects.kt:33-34`（「之后抬 padding 也能生效，但会重跑一次 effects 块」） |

### 5.5 低端机降级策略（基于源码能支持的三种）

1. **能力闸门**：`if (!isRenderEffectSupported()) 不建 backdrop` → 全链路自动回退到 `surface` 实色（SukiSU 就这么做的，`[S]ui/util/BlurExt.kt:17`）。
2. **开关闸门**：把一个 `enableBlur` 布尔从设置页透到 CompositionLocal（SukiSU 的路子，见 §4.3）。
3. **半径闸门（本册建议，源码支持但 SukiSU 未用）**：`BlurDefaults.MaxBlurRadius = 150f` 已经有 clamp（`[L]blur/BackdropEffects.kt:395`），可以按设备档把 25f 降成 12f/8f——档位表见 §3.1，半径跨档会改变降采样倍数，这是唯一能真正省 GPU 的旋钮。
