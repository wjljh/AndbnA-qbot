## 六、常见问题

| 现象 | 处理 |
|---|---|
| `error: RPC failed; HTTP 500/curl 56` | `git config http.postBuffer 524288000` 后重试；仍失败改用 SSH |
| 卡在 `Writing objects` 很久 | 网络问题；`.git` 只有 9.3 MB，正常应在 1 分钟内 |
| 提示 `! [rejected] main -> main (fetch first)` | 建仓时勾了 README：`git pull --rebase origin main` 再 push |
| 想改仓库名/大小写 | GitHub Settings → Repository name 直接改，URL 自动跳转 |
| PAT 用完 | 立刻到 Settings → Developer settings → Tokens 撤销 |
